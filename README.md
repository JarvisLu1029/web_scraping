# 🕸️ Web Scraping 教學

> 從零開始學習網頁爬蟲的完整教學課程

---

## 📚 課程總覽

本課程涵蓋網頁爬蟲的核心技術，從基本的 HTTP 請求到自動化瀏覽器操作，循序漸進地帶你掌握資料擷取技能。

---

## 🗂️ 課程模組

| 模組 | 主題 | 內容概述 | 難度 |
|:---:|:---|:---|:---:|
| 🌐 [1-Requests](./1-Requests/) | **HTTP 請求** | 發送請求、處理回應、API 使用 | 🟢 入門 |
| 🍜 [2-BeautifulSoup](./2-BeautifulSoup/) | **HTML 解析** | 解析 HTML、元素定位、資料提取 | 🟢 入門 |
| 🔍 [3-Regex](./3-Regex/) | **正規表達式** | 字元匹配、群組捕捉、Python re 模組 | 🟡 基礎 |
| 🤖 [4-Selenium](./4-Selenium/) | **自動化瀏覽器** | 動態網頁、元素操作、等待機制 | 🟠 進階 |
| 🖥️ [5-PyAutoGUI](./5-PyAutoGUI/) | **桌面自動化** | 滑鼠鍵盤控制、截圖、圖像辨識 | 🟠 進階 |

---

## 🎯 學習路徑

```
1-Requests ➜ 2-BeautifulSoup ➜ 3-Regex ➜ 4-Selenium ➜ 5-PyAutoGUI
  HTTP 請求     HTML 解析       正規表達式    自動化瀏覽器    桌面自動化
```

---

## 📋 難度說明

| 標示 | 等級 | 說明 |
|:---:|:---:|:---|
| 🟢 | 入門 | 適合具備基本 Python 語法的初學者 |
| 🟡 | 基礎 | 需要了解基本網頁結構（HTML/CSS） |
| 🟠 | 進階 | 需要熟悉前面章節的技術 |

---

## 🚀 開始學習

1. 確保已安裝 Python 3.x
2. 依序安裝各章節所需套件
3. 依照模組順序學習，完成每個模組的練習題
